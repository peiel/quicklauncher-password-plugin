# QuickLauncher 密码生成插件

一个本地密码生成插件：输入 `gpwd` 并按回车，生成并复制 24 位密码。密码包含大写字母、小写字母、数字以及 `+` 或 `/`，使用系统 OpenSSL 的密码学随机源生成；脚本不联网，不记录密码。

## 安装

在 QuickLauncher“设置 → 脚本与插件 → GitHub 插件”中搜索本仓库，审阅后确认安装。插件默认停用，检查代码后单独启用。`gpwd` 与内置密码插件的 `pwd` 分开，可在插件设置中自定义触发词。

密码复制后，能够读取系统剪贴板的其他应用或剪贴板管理工具仍可能获取它。插件以当前用户身份运行，请先检查源码。

## 要求

macOS，QuickLauncher，系统 `/bin/zsh` 和 `/usr/bin/openssl`。无额外依赖。

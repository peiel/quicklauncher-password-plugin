# QuickLauncher 密码生成插件

一个本地密码生成插件：输入 `gpwd` 并按回车，生成并复制随机密码。密码包含大写字母、小写字母、数字以及 `+` 或 `/`，使用系统 OpenSSL 的密码学随机源生成；脚本不联网，不记录密码。

默认长度由 QuickLauncher 的密码长度设置决定（初始为 24 位）；输入 `gpwd 32` 可为本次生成指定长度，支持 8–128 位。较短密码强度更低，建议至少 16 位。

## 安装

在 QuickLauncher“设置 → 插件 → 发现插件”中搜索本仓库，审阅后确认安装。插件默认停用，检查代码后单独启用。默认触发词为 `gpwd`，可在插件设置中自定义。

密码复制后，能够读取系统剪贴板的其他应用或剪贴板管理工具仍可能获取它。插件以当前用户身份运行，请先检查源码。

## 要求

macOS，支持密码长度输入的 QuickLauncher，系统 `/bin/zsh` 和 `/usr/bin/openssl`。无额外依赖。
